# ejemplos/

Ejemplos **anonimizados** de trabajos reales, uno por caso en `ejemplos/<caso-código>/` (por ejemplo `caso-ds-01`). Aquí no entran marcas, textos, imágenes ni archivos de clientes; solo lo que enseña el método: un plan de arranque rellenado, un contrato mínimo, una tabla de vocabulario, una ficha de auditoría o los resultados de un verificador, con nombres genéricos.

| Caso | Contenido | Estado |
|---|---|---|
| `caso-ds-01` | Ejemplos del primer caso (sitio web propio del mantenedor) | Se añaden tras la prueba (C-7) |

Antes de añadir un ejemplo, pásalo por `python <repo>/tools/privacy_scan.py`.
