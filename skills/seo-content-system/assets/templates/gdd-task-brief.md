## Orden de dependencias del GDD (no invertir)
Kick off → insumos y accesos → benchmark UX + competencia SEO + auditoría → clasificación de URLs → KWR → persona → journey → arquitectura de información → plan de redirecciones → contenido de las páginas de alto impacto → matriz de metadatos → wireframe → UI Kit / Home.

Los metadatos van **después** del contenido aprobado, y el wireframe se diseña con el contenido ya listo. Cada etapa se socializa primero con el equipo y luego con el cliente.
