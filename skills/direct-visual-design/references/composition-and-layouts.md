# Composición, retículas y layouts

## Contenido

1. Arquitectura visual
2. Retículas
3. Jerarquía y flujo
4. Densidad y espacio
5. Responsive y multiformato

## 1. Arquitectura visual

Construir una composición desde relaciones, no desde coordenadas aisladas:

- prioridad y secuencia;
- ejes y alineaciones;
- escala y proporción;
- balance simétrico o asimétrico;
- ritmo, repetición y variación;
- figura-fondo y profundidad;
- tensión, pausa y espacio negativo;
- bordes, recortes y zonas seguras.

Usar blur o squint test para detectar masas y jerarquía, pero volver a tamaño real para evaluar detalle y legibilidad.

## 2. Retículas

Elegir según contenido y medio:

| Retícula | Uso frecuente | Riesgo |
|---|---|---|
| Manuscrito | Texto continuo, libros, ensayos | Monotonía si no existe ritmo secundario |
| Columnas | Editorial, web, presentaciones | Columnas demasiado estrechas o relaciones arbitrarias |
| Modular | Datos, catálogos, dashboards | Rigidez y fragmentación excesiva |
| Jerárquica | Campañas y layouts de contenido diverso | Falta de consistencia si no se documentan ejes |
| Baseline | Sistemas tipográficos y editorial | Forzar imágenes o componentes sin necesidad |
| Libre/expresiva | Afiche, cultura, moda, experimentación | Perder lectura, producción o adaptación |

No exigir 12 columnas. Definir columnas, márgenes, gutters y módulos según ancho, contenido, breakpoints y tecnología.

## 3. Jerarquía y flujo

Definir entrada, recorrido probable, pausas y salida. Diseñar una jerarquía con niveles, no necesariamente un solo foco.

- Colocar la información crítica donde sea detectable y esperable.
- Usar contraste por escala, valor, forma, espacio, posición o movimiento.
- Evitar que todos los elementos compitan con máxima intensidad.
- No asumir que superior izquierda o inferior derecha garantizan atención o conversión.
- Usar F, Z, Gutenberg o layer-cake como hipótesis informadas; validar la tarea real.

## 4. Densidad y espacio

El espacio negativo debe sostener agrupación, lectura, ritmo o tono. No “añadir aire” sin considerar contenido y formato.

- Diferenciar espacio interno, entre elementos relacionados, entre grupos y perimetral.
- Mantener relaciones consistentes mediante una escala de espacio cuando el proyecto lo requiera.
- Permitir densidad alta en interfaces expertas si jerarquía y escaneo siguen siendo claros.
- Evitar tarjetas o divisores cuando espacio y alineación ya comunican la relación.

## 5. Responsive y multiformato

Adaptar por recomposición:

1. conservar mensaje y prioridad;
2. recalcular zona segura;
3. cambiar recorte o relación imagen-texto;
4. reordenar bloques;
5. ajustar escala y longitud de línea;
6. simplificar contenido secundario con autorización;
7. validar en tamaño y contexto real.

No extrapolar automáticamente un layout vertical a horizontal. Preparar reglas de recorte, anclaje y reemplazo de assets.
