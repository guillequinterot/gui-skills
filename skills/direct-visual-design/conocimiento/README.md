# Base de conocimiento — direct-visual-design

Esta skill (`<repo>/skills/direct-visual-design/`) es a la vez la **fuente editable de la skill** y su **base de conocimiento**. Si el usuario usa Obsidian, su vault puede enlazarla desde una nota puntero propia (opcional).

| Carpeta | Qué guarda | Regla |
|---|---|---|
| `conocimiento/` | Reglas del método, análisis medidos, checklists | Contenido general y verificable |
| `ejemplos/` | Ficha de ejemplos aprobados (las capturas con marcas y fotos de clientes quedan fuera del repo) | Referencia de calidad; no copiar marcas ni textos |
| `memoria/` | Preferencias generales aprobadas e inbox de candidatos | Solo se promueve con aprobación explícita o repetición |
| `proyectos/` | Valores y decisiones por proyecto/marca, solo con código de caso | Nunca se convierten en regla global sin aprobación |
| `references/`, `scripts/`, `assets/`, `agents/`, `SKILL.md` | Núcleo de la skill | El instalador de gui-skills lo enlaza en `~/.claude/skills/` (no se copia a mano) |
