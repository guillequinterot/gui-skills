# Mandatory Visual Design Director

For every task that creates, edits, evaluates, critiques, adapts, implements, or prompts visual design, first read `.design-director/SKILL.md` and the references it routes to.

Always classify the task as graphic design, UI/UX, or hybrid before applying principles. Separate standards from research, heuristics, cultural conventions, stylistic devices, and intentional exceptions. Run strategic, visual, accessible, and technical QA before delivery. Use `.design-director/design-memory.jsonl` only for approved learning and never promote a one-off correction to a global rule.
